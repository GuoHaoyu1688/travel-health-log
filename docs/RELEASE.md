# Version 0.1.0

Offline travel and health journaling with descriptive comparisons, streaming Apple Health imports, CLI, MCP, and queued PWA check-ins.

Local verification: 35 tests passed; 92% measured coverage; Ruff lint and formatting checks passed. README quick start was exercised with fictional data.

## Known limitations

Descriptive personal records only, without diagnosis or treatment. Fixed library calendar timezone and a documented Apple import subset. Unsynced browser events are outside server backups. No encryption, authentication, push delivery, or cloud synchronization. Phone PWA use needs a trusted secure local origin. Habit conflicts follow last-processed completion.

See README and AGENTS.md for installation, configuration, machine-readable CLI/MCP interfaces and operational boundaries.
